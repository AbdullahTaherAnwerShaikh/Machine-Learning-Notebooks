# Machine Learning Practice

A collection of machine learning and deep learning models I build while learning **fast.ai** and developing practical skills in **computer vision, deep learning, and machine learning**.

The purpose of this repository is to document my progress, experiment with different ML techniques, and build models from different types of datasets.

## 📚 Topics

This repository currently covers:

* 🖼️ Image Classification
* 🎨 Image Segmentation
* 📊 Tabular Machine Learning
* 🧠 Transfer Learning
* 🔧 Model Training & Fine-Tuning
* 📈 Training & Validation
* 📉 Loss and Metrics
* 🗂️ Dataset Preparation

More topics will be added as I progress through the course.
